# 使用指南

本指南介绍页面操作和日常使用。首次安装、登录与安全配置见 [README](../README.md)；服务部署及数据备份见 [部署与运维](deployment.md)。

## 建议顺序

1. 登录并修改管理员密码。
2. 在「系统设置」配置需要的代理、凭据和验证码服务，使用测试按钮确认连接。
3. 在「模板管理」建立通用流程，或导入可信来源的模板配置。
4. 在「站点管理」添加站点、选择模板、保存登录来源并调整站点步骤。
5. 先手动运行一个站点，检查步骤结果、日志和页面，再启用自动调度。
6. 在「通知设置」配置结果推送，通过「运行分析」持续查看执行情况。

## 系统设置

代理、2FAuth、CFbox、Bitwarden 和视觉模型可在此保存、测试或清除。字段会显示来源：环境变量提供的配置只读；页面保存的配置可以继续编辑。

- 配置代理后，站点才能使用代理车道。代理失败时不会自动改为直连。
- 使用 Bitwarden 时，填写服务地址和访问令牌，或使用部署自带的服务；同时配置该服务需要的保险库凭据。
- 使用 Turnstile 功能前配置 CFbox 地址。仅当 CFbox 自身启用鉴权时填写 API Key。
- 使用视觉验证码或图片答题时，配置支持图片输入的模型，并先测试服务连接。
- 调度支持关闭、定时、间隔和随机时间范围，可设置时区；环境变量指定的字段不能在页面修改。
- 可查看任务日志和截图的保留设置、数量及空间占用，按需要执行清理。清理前确认不再需要这些排查资料。

完整字段与环境变量见 [集成配置](configuration.md)。

## 模板与功能

「功能管理」可查看各类功能的配置字段、必填项及所需服务。通用默认值可在支持的功能设置中调整；具体站点的差异优先在站点中覆盖。

在「模板管理」新建模板并添加分组和步骤。选择功能后填写对应字段，保存前补齐必填项。已有类似流程时，可选择父模板，再调整需要覆盖的步骤。

- 步骤可保持继承、强制启用，或保留配置但禁用。
- 使用上下移动调整步骤顺序；在模板中定义的顺序会沿用到站点。
- 修改继承步骤时点击「修改步骤」；需要回到父级配置时使用恢复继承。
- 「代码配置」可粘贴 JSON 批量编辑当前步骤，应用前检查字段和错误提示。
- 模板和站点步骤的 key 由系统生成。使用条件跳转时选择目标步骤，不手工改写 key。
- 页面信号可配置包含/排除文本或选择器，步骤条件引用这些信号。保存前确保被引用的信号存在；无法判断的条件会要求人工检查。
- 条件跳转可跳到指定步骤或重新开始，需设置合理的跳转次数限制，避免反复提交操作。

### 选择器与元素拾取

选择器可填写多个候选，系统按顺序使用第一个匹配项。优先使用能唯一定位目标的选择器，避免泛用的 `button`、`input` 等误点其他操作。

点击选择器字段旁的「拾取」，在交互车道打开页面。必要时先正常登录，再按住 **Alt/Option** 点击目标元素，确认生成的选择器。拾取会话默认 15 分钟过期，完成后关闭会话。

## 站点与登录

在「站点管理」添加名称和基础地址，选择模板，然后检查展开的步骤。步骤地址可使用 `{base_url}`，运行时替换为当前站点地址。

继承字段可以单独覆盖；点击「修改步骤」调整模板步骤，不需要复制整套流程。保存后查看解析预览，核对最终步骤、条件和参数。

「登录凭据」中选择适合的来源：

- **账户**：首次填写用户名和密码；以后可以单独更新，密码不回显。
- **Cookie**：粘贴浏览器 Cookie 请求头或支持的 JSON。保存后不回显明文，过期时重新导入。
- **Bitwarden**：启用集成后选择域名匹配方式；有多个相似域名时检查完整域名、主域名或自定义匹配是否符合预期。
- **插件提供商**：先在插件管理中完成接入和审批，再在对应标签启用，并设置匹配方式。

外部凭据来源互斥，不要同时启用多个提供商。远程凭据不会自动写入手动账户字段。更换来源后先做单站点验证。

### 跨域登录与可信网址

站点编辑器的「备注」上方可添加可信 URL 正则数组。默认空数组，仍仅允许在站点同源页面读取和填写登录凭据/TOTP。跨域 SSO 必须显式授权，不能仅凭导航步骤自动信任。

例如基础地址为 `https://www.natfrp.com`，需要授权 `https://openid.13a.com/login` 及其查询参数时，添加：

```text
^https://openid\.13a\.com/login(?:[/?#].*)?$
```

每条 Python `regex` 正则对浏览器完整 URL（含路径、查询和片段）进行全匹配，任意一条匹配即可；最多 20 条，每条 1024 字符，匹配限时 25ms。请根据实际登录路径收窄规则，域名的 `.` 应转义为 `\.`，不要使用 `.*` 信任所有网址。只允许合法 HTTP(S) URL，URL 中的用户名/密码无论匹配与否均拒绝。

这是敏感凭据授权，不是普通导航白名单。配置仅对本站点的内置登录与 2FA 生效，不扩大插件浏览器代理权限，不自动同步跨域 Cookie，也不改变 Bitwarden 的凭据匹配方式。复制或导入站点时会带上规则，使用前应逐条审核。清空数组可撤销额外授权，未匹配时仍提示 `Secret origin denied`。

需要 2FA 时，在对应步骤选择提供商，填写 **2FA 服务名**；同服务有多个账户时再填写 **2FA 用户名**。无论使用内置 2FAuth 还是插件，服务名都不能为空。

### 验证与签到

根据站点实际页面添加功能，不必把所有验证方式都开启：

- 图形验证码可选择 ddddocr、视觉模型、NexusPHP GD 5 或已批准插件方法；按验证码填写字符集与长度。置信度阈值仅适用于 ddddocr。
- 识别失败时可配置刷新或重新开始，并限制重试次数。视觉模型与 GD 5 不会自动退回 ddddocr。
- Turnstile 需要 CFbox；ALTCHA 使用独立验证功能。成功组件仍可能显示在页面，不必等待它消失。
- 通过按钮、导航、iframe 签到或 UNIT3D Claim 等步骤完成操作，再配置明确的成功信号和结果输出。
- 验证步骤成功不代表站点服务端一定接受提交。出现 `Captcha verification failed` 等提示时，检查提交后的截图和日志，不要无限重试。

### 补签与购买

站点启用「支持补签」并设置最大天数后，使用「断签」信号判断是否需要执行补签步骤。补签卡购买和补签均使用站点设置的范围。

购买步骤可能实际消耗积分或余额。先核对价格、购买限制与条件，不要在不了解页面行为时对正式账户反复测试。

### 车道选择

通过「使用代理」和「优先交互」选择车道。普通通用、代理通用可并行执行；交互车道一次只执行一个任务，适合需要人工查看或桌面坐标操作的流程。

## 导入与导出

模板和站点列表均支持勾选部分或全部项目后导入导出。导入前查看预览，处理同名项、父模板缺失或字段错误；同名项会跳过，不会直接覆盖。

站点导出包含流程配置，不包含保存的登录密码和 Cookie。导入后按需要重新设置凭据，并先手动验证再启用调度。自定义步骤字段仍可能包含敏感值，分享前应自行检查。

可使用 [插件 Demo](../plugins/examples/demo/README.md) 的单站点导入配置熟悉流程。它使用固定公开测试凭据，不用于真实账户。

## 执行与排查

可以从站点列表直接执行，也可以在「任务调度」选择站点运行。批量执行支持全部启用且有效的站点，或今天尚未成功且当前未在排队/运行的站点。

站点的最早签到时间与系统调度共同决定自动执行时机，日期按所设调度时区判断。

在运行详情中：

- 按站点切换子标签，查看每步状态、消息和输出。
- 切换「详细日志 / 状态日志」，定位等待、失败或超时原因。
- 打开失败截图，确认页面是否仍有挑战、已跳转，或出现站点错误提示。
- 任务运行中可以取消；系统会取消在途操作并清理任务页面，但已提交的请求不能撤回。
- 点击车道名进入任务对照视图，使用「定位任务标签页」查看该任务实际页面。

需要人工操作时，进入对应车道 VNC。任务结束通常会关闭其标签页，因此保留的失败截图和日志是排查历史运行的主要依据。重新运行前确认是否已签到或已发生购买，避免重复操作。

## 浏览器与人工操作

「车道状态」中可手动启动、进入 VNC 或关闭浏览器，也可等待任务按需启动。

- 退出 VNC 只关闭查看连接，不停止浏览器。
- 有任务执行时禁止关闭浏览器。
- 没有任务或 VNC 查看者时，超过空闲时间会自动关闭；默认 300 秒，设置 `0` 则禁用空闲关闭。
- 关闭浏览器保留 profile 数据，下次启动继续使用。不要在外部 Manager 中同时修改或关闭 SiteFlow 正在使用的 profile。
- 可在车道设置调整空闲时间及通用车道并发数；普通默认 5、代理普通默认 3，交互固定 1。

浏览器相关更新前请先结束任务并退出人工会话，避免中断执行。

## 插件管理

先按插件文档部署其容器并配置独立令牌，再在 SiteFlow「插件管理」查看注册结果和检查项。插件容器的安装、更新和删除由部署工具处理，不在 SiteFlow 页面执行。

1. 检查插件来源、声明能力和配置要求，确认可信后审批。
2. 审批完成后，在工作流、验证码方法或凭据/2FA 提供商中选择插件。
3. 插件不可用时检查容器状态、心跳和检查结果，不要通过反复审批掩盖连接故障。
4. 更新后先查看引用及影响提示，修复不兼容配置，再按要求重新审批。

停用会阻止接入但保留配置；撤销审批后需重新授权。移除接入不删除外部容器，恢复后也需重新审批。可通过审计列表查询相关管理操作。

## 通知与运行分析

在「通知设置」启用邮件或 HTTP 渠道，填写地址和必要凭据，发送测试确认可达。按需选择仅失败通知、自动调度通知，调整公共标题和正文；支持 `{{run_id}}`、`{{status_label}}`、`{{sites}}` 等变量。环境变量指定的字段在页面只读。

通知失败不会改变任务结果。详细模板与渠道配置见 [通知设置](notifications.md)。

「运行分析」提供站点与日期状态矩阵、趋势和失败筛选。点击记录进入运行详情，通过日志和截图判断是否需要修改流程、凭据或服务配置。

## 账户

右上角账户菜单可修改密码或退出登录。管理员密码由环境变量管理时，需修改部署配置后更新服务，不能在页面改密。不要将自己的登录会话分享给其他人。
